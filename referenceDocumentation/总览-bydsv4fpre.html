🧠 AI Agent 开发路线图

从0到“社会人” · 四阶段可实践方案 · 开源项目推荐

本路线图遵循 “先跑通核心链路，再逐层叠加能力” 的原则，参考了 Neuro-sama 的演进路径。 每个阶段都提供可直接使用的开源项目，适合从零开始的开发者。

阶段零 · 核心链路 STT → LLM → TTS

目标：让 Agent “能说话”——跑通语音识别、大模型推理、语音合成的完整管道。

推荐项目

AITuber OnAir（TypeScript）
专为构建 Neuro-sama 风格的 AI Vtuber 设计，开箱支持聊天、说话、回应观众、记忆、PNG/VRM/Live2D 形象。
AI_Vtuber_2.0（Python）
使用 OpenAI Realtime API 实现实时语音交互，集成 B站/YouTube 弹幕输入，含 Flask 监控界面。
StreamCream（Python）
Live2D + GPT-SoVITS 全自动直播方案，包含文案生成和模型表情动作控制。

行动：选一个项目克隆，配置好 API 密钥（LLM + TTS），跑通并听到 AI 说话即成功。

阶段一 · 记忆系统 持久化

目标：让 Agent “记住”历史，从“每轮失忆”变为拥有连贯上下文。

轻量入门方案

nanoAgent（Python，~200行）
极简 Agent 实现，agent-memory.py 仅 206 行，演示持久记忆与任务分解，适合先读懂原理。
memory-trigger（即插即用）
挂载一份长期记忆，不被上下文窗口压没。直接放入 Agent 目录即可使用，支持命令行模式。
agent-knowledge（Python，pip install compiled-memory）
自动将会话编译为结构化知识，带主张/证据追溯。
llmem（Python）
基于 SQLite 的持久记忆服务，支持自动合并相似记忆，跨会话持久化。

行动：在 Agent 上挂载 memory-trigger 或 llmem，让它能记住上一轮聊过的内容。

阶段二 · 人格与一致性 身份

目标：让 Agent 拥有稳定、独特的“自我”，每次回复都像同一个人。

推荐项目

ego-mcp（MCP 服务器）
让 LLM Agent 跨会话保持一致的人格、记忆和情绪，自带实时观测仪表盘，不绑定特定 LLM。
openhanako（Python）
“有记忆、有性格、会主动行动”的个人 AI Agent，通过人格模板和自定义人格文件塑造独特性格。
SoulLink（为 Hermes Agent 设计）
运行时让 Agent “感觉像是同一个人”，包含实时情绪检测、长期记忆、上下文管理。
Neuro-sama 官方身份框架
包含人格引擎（性格特征+情绪建模）、记忆系统（情景记忆+工作记忆）、认知管道。

行动：编写一个“人设文件”（名字、性格标签、说话风格），通过 ego-mcp 或 openhanako 的模板机制加载，使 AI 保持风格一致。

阶段三 · 完整互动 感知与行动

目标：Agent 能看弹幕、控制模型、玩游戏，接近 Neuro-sama 的完整形态。

推荐项目

Neuro-sama 官方 API（WebSocket 服务器）
包含完整的 Neuro-sama 人格实现，可作为 WebSocket 服务器运行，可通过 Neuro API 连接游戏，提供 Rust SDK。
SwarmClone（全开源 AI 虚拟主播）
专为 B站、Twitch 等平台设计的高质量实时互动，框架灵活可扩展。
Megumi（模块化 AI Vtuber）
个人开发的模块化项目，目标“做一个像 Neuro 那样的 AI Vtuber”，通过 core server + 多进程 + WebSocket 实现组件互联，结构清晰。
TheDyingYAK/Neuro-sama（复刻项目）
7 天内复刻 Neuro-sama，全部运行在本地模型上，消费级硬件可跑，是最接近“手把手教你做一个 Neuro-sama”的参考实现。

行动：参考 TheDyingYAK/Neuro-sama 或 SwarmClone，集成弹幕交互、模型控制和游戏联动。

💡 核心建议
• 不要一开始追求“完整社会人”，先让阶段零跑起来——听到 AI 开口说话的那一刻，成就感会推着你往前走。
• 记忆系统从最简单的开始：nanoAgent 的 206 行代码读一遍，你就理解记忆系统的本质了。
• 人格一致性在记忆之后再加——记忆是“骨架”，人格是“血肉”，顺序不能反。

“Agent 的一切都是记忆——人格是‘我记得我是谁’，规则是‘我记得该怎么做事’，技能是‘我记得怎么做某类事’。”

从今天开始，选一个项目克隆下来，把核心链路跑通。剩下的，一步一步来。
