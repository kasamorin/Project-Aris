# note 备忘技能

记录简短笔记（给未来的自己/Aris 用），持久化在本地 `data/notes/`。

## 使用场景

- 用户说「记一下 X」「帮我记个备忘 Y」→ 用 note_save 保存
- 用户说「我之前记了什么」「我有什么备忘」→ 用 note_list + note_read 查看

## 工具

- `note_save(title, content)`：保存/更新一条笔记（标题唯一，重复保存覆盖）
- `note_read(title)`：读取一条笔记内容
- `note_list()`：列出所有笔记标题

## 注意事项

- 标题要简短（几个词即可），内容写完整
- 笔记是文本，保存后下次会话仍在（本地持久化）
- 只在用户明确要求记录/查看时使用，不要自作主张保存对话本身
